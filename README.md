SNAKE GAME

A Snake game built using Python and Pygame. Control the snake using your arrow keys for it to eat the green food and make the score go as high as you can make it!

TECHNOLOGIES USED
- Python 3.x
- Pygame library

 HOW TO INSTALL?
 1. Install the latest version of Python from python.org
 2. Open the terminal and install the Pygame (library): 
         | pip install pygame |

HOW TO RUN? 
 Save the code as Snake_Game.py, then run:
   python Snake_Game.py

HOW TO PLAY?
- Use the arrow keys to control the snake
- Eat the green food to grow and it will add a point to your score card
- Avoid hitting the walls of the window or even your own body
- When the game ends, You get a message box with two options choose any one:
   - press C to play again
            OR
   - press Q to quit the game and leave the window

CUSTOMIZE IT!
You can customize these values at the top of the code:
 
Setting           | What it does?
 ---------------------------------------------------------
WIDTH, HEIGHT     | Size of the Game Window
 ---------------------------------------------------------
SPEED             | How fast the snake moves(higher=faster)
 ---------------------------------------------------------
BLOCK_SIZE        | Size of the snake and food
 ---------------------------------------------------------
